# Seoul 마사지 — 서울 출장마사지·홈타이 안내 사이트

서울 전역을 대상으로 한 방문 건강관리(출장마사지·홈타이) 예약 안내 **정적 사이트**입니다.
순수 HTML(인라인 CSS/JS, 런타임 의존성 0) + Python 단일 생성기로 만들어지며,
구글/네이버 SEO 가이드라인과 **도어웨이·중복·얇은 콘텐츠 회피** 원칙을 따릅니다.

## 구조

```
서울 > 자치구(25) > 대표 동
지하철: 노선(17) > 주요 역
테마(14)
코스 / 예약안내 / 이용가이드 / 후기 / 고객센터 / 정책
```

- 상단 메뉴: 홈 · 서울 출장마사지 · 지역별 안내 · 지하철역별 안내 · 테마별 안내 · 코스안내 · 예약안내 · 이용가이드 · 후기 · 고객센터
- 메뉴명에 키워드를 반복하지 않고, **SEO Title·H1에서만** 핵심 키워드를 사용합니다.
- 숫자 행정동(논현1·2동 등)은 별도 페이지 없이 **대표 동 페이지에서 통합 안내**.
- 지역+역+테마 **조합 페이지는 생성하지 않습니다**. 출구별 페이지도 없습니다.

## 생성 규모 (현재)

| 구분 | 수 |
|---|---|
| 메인/대표/허브 | 홈·서울대표·지역허브·지하철허브·테마허브·서울FAQ |
| 자치구 | 25 |
| 대표 동 | 117 (구별 3~6개) |
| 지하철 노선 | 17 |
| 주요 역 | 16 |
| 테마 | 14 |
| 코스 | 8 (+허브) |
| 예약·가이드 세부 | 11 |
| 정책(noindex) | 3 |

**인덱스 콘텐츠 페이지 218개 전부 본문 2,000자 이상**(평균 ≈ 2,250자, 공백 포함).
정책 3종은 분량이 적은 법적 고지 페이지라 `noindex` 처리하고 사이트맵에서 제외합니다.

## 도어웨이 회피 (BLUEPRINT.md §4 기준)

- 페이지마다 1차 데이터(자치구·동 성격·랜드마크·생활권·역) 주입 + **문장 변형 엔진**으로 유사도 관리.
- 공통 정보(예약시간·준비물·위생·요금)는 본문 반복 대신 **전용 페이지로 링크아웃**.
- 4-gram 자카드 유사도(쌍별): 자치구 ≈ 27% / 대표 동 ≈ 35% / 테마·노선·역 ≈ 40% (목표 ~40% 이하).

## 빌드

```bash
python3 tools/build.py          # 전체 HTML + sitemap.xml + robots.txt + manifest 생성 (글자수 리포트 출력)
pip install pillow && python3 tools/gen_icons.py   # 파비콘·PWA·OG 이미지 생성
python3 tools/indexnow.py --all # 빙·네이버 즉시 색인 통보 (배포 후)
```

빌드 도구·프레임워크 없이 정적 HTML이 그대로 배포됩니다. 공통(헤더/푸터/SEO/스키마)을
바꿀 때만 `tools/build.py`를 다시 실행하세요.

## 코드 구성

```
tools/build.py          # 생성기 (페이지 빌더 + 콘텐츠 변형 엔진 + sitemap/robots/manifest)
tools/data_seoul.py     # 데이터 모델 (권역·자치구·대표 동·노선·역·테마)
tools/theme_assets.py   # 공유 CSS / JS (다크 럭스 디자인 시스템)
tools/gen_icons.py      # 브랜드 이미지 (Pillow)
tools/indexnow.py       # IndexNow 색인 통보
tools/google_indexing.py
.github/workflows/indexnow.yml
BLUEPRINT.md            # 재사용 플레이북
```

## 실서비스 전 교체할 상수 (`tools/build.py` 상단)

- `BASE_URL` (배포 도메인) · `BRAND` · `PHONE_DISP` / `PHONE_TEL`
- `COMPANY` (상호·대표·사업자번호·주소·통신판매신고·개인정보책임자)
- `INDEXNOW_KEY` (새 키 발급)

> 본 서비스는 의료 행위가 아닌 이완·휴식 목적의 건강관리 서비스이며 만 19세 이상 성인을 대상으로 합니다.
